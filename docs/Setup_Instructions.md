# Setup Instructions – AirTribe LearnTrack

This document provides step-by-step instructions to set up and run the **AirTribe LearnTrack** CLI-based Java application on a local machine.

---

## 📌 Project Overview
- **Application Type:** Command Line Interface (CLI)
- **Language:** Core Java
- **Storage:** In-memory database using `HashMap`
- **Frameworks:** None

---

## 🛠️ Prerequisites

Ensure the following are installed on your system:

### 1. Java Development Kit (JDK)
- JDK 8 or higher
- Verify installation:
```bash
java -version
```
## Environment setup
- Java must be added to system PATH
- Command line access (Terminal / CMD / PowerShell)

## Clone the Repository
- git clone https://github.com/MukundSurvase/AirTribeLearnTrack.git
- cd AirTribeLearnTrack
