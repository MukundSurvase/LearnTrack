# AirTribe LearnTrack 🚀

**AirTribe LearnTrack** is a **CLI-based Java application** built using **Core Java**, designed to simulate a simple learning management and tracking system.  
The application uses **in-memory data storage (HashMaps)** to manage users, login details, and application flow.

This project is ideal for understanding **Java fundamentals**, **object-oriented programming**, and **CLI-based application design**.

---

## 🧩 Project Type
- **Command Line Interface (CLI) Application**
- **Standalone Java Program**
- No web server, no external database

---

## ✨ Features
- CLI-based interactive menu system
- User login and authentication simulation
- Employee / user data stored in memory
- Uses `HashMap` as an in-memory database
- Simple and beginner-friendly Java architecture
- Demonstrates real-world Java application flow

---

## 🛠️ Tech Stack
- **Language:** Java (Core Java)
- **Frameworks:** None (Pure Java)
- **Database:** In-memory storage using `HashMap`
- **Build Tool:** None (Plain Java compilation)

---
